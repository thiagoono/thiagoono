## 🚀 Projetos em destaque

### 📝 [Gerenciador de tarefas — CS50x](https://github.com/thiagoono/projeto-final-cs50)

Aplicação web para organizar tarefas diárias, com autenticação de usuários, gerenciamento de tarefas, recorrência e detecção de conflitos de horários.

**Tecnologias:** Python, Flask, SQLite e SQL.

[Ver repositório](https://github.com/thiagoono/projeto-final-cs50) · [Assistir à demonstração](https://youtu.be/UrrcTZfCVEg)

### ⏱️ [Cronômetro](https://github.com/thiagoono/cronometro)

Cronômetro com registro de múltiplos tempos, armazenamento local, ordenação dos registros e atalhos de teclado para controlar as funções principais.

**Tecnologias:** HTML, CSS e JavaScript.

[Ver repositório](https://github.com/thiagoono/cronometro) · [Experimentar online](https://thiagoono.github.io/cronometro/)

### 🎲 [Sistema de sorteio de cargos](https://github.com/thiagoono/Sorteio)

Ferramenta desenvolvida para uma atividade da Ordem DeMolay. Permite cadastrar participantes e cargos, definir a ordem do sorteio e retirar automaticamente os participantes já sorteados.

**Tecnologias:** HTML, CSS e JavaScript.

[Ver repositório](https://github.com/thiagoono/Sorteio) · [Experimentar online](https://thiagoono.github.io/Sorteio/)

### 🎨 [Landing page](https://github.com/thiagoono/projeto-final-landing-page)

Página desenvolvida como projeto final de um curso de HTML e CSS, com foco na estruturação e estilização de uma interface web a partir de uma referência visual.

**Tecnologias:** HTML e CSS.

[Ver repositório](https://github.com/thiagoono/projeto-final-landing-page) · [Experimentar online](https://thiagoono.github.io/projeto-final-landing-page/)
